at least **4** items. The 4 is not arbitrary: `generateQuestions` returns `[]` for a pool
under 4, so 4 is the smallest set that can actually run a quiz.

## The thing worth knowing before you write

**Five existing entries are sitting at a level above their real difficulty.** Look at these:

| Entry | Sits at | Reads as |
|---|---|---|
| 開燈 / 關燈 (turn on/off the light) | Home **L2** | **Beginner** |
| 開門 / 關門 (open/close the door) | Home **L3** | **Beginner** |
| 開窗 (open the window) | Home **L2** | **Beginner** |
| 街市 (market) | Shopping **L2** | **Beginner** |
| 瞓覺 (sleep) · 起身 (wake up) · 沖涼 (shower) | Daily Life **L2** | **Beginner** |

So "Home has no Beginner words" is partly **a filing error, not a content gap**. Moving
開燈/關燈/開窗 to L1 clears three of Home's four slots with words that already exist and
are already beginner-appropriate.

**You have two ways to close each gap, and re-levelling is free:**

| | New words written | Effort |
|---|---|---|
| **Move** the easy ones down | as few as ~20 | no new Jyutping, no new glosses |
| **Write** fresh L1 words | 36 | full authorship |

I'd suggest **moving first, then writing whatever is still short.** It is less work *and*
it puts each word in front of the learner who can actually use it — a beginner needs
開燈 (turn on the light) on day one, not at Advanced. But the level you assign is a
teaching judgement and yours to make; the only hard requirement is that no combination
ends up empty.

## What each new entry needs

`data.js → SEED_VOCABULARY`, one object per word:

| Field | Notes |
|---|---|
| `cantonese` | Traditional characters, as used in Hong Kong |
| `jyutping` | **The hard part.** Tone digit on every syllable (`nei5 hou2`) |
| `english` | The gloss |
| `tagalog` | Filipino gloss — half this audience |
| `mandarin` | Simplified Chinese gloss |
| `indonesian` | Indonesian gloss — the other half |
| `emoji` | One, matching existing style |
| `level` | 1, 2 or 3 |
| `category_id` | Must match a category in `SEED_CATEGORIES` |

Optional, present on many rows: `type`, `speaker`, `example_yue`, `example_jyutping`,
`example_en`, `usage_note`, `tags`, `sort_order`.

**Level is difficulty, not a label.** L1 = single words and first-week essentials.
L2 = short daily-action phrases (煮飯 to cook). L3 = full sentences.

## Notes

- **`status: 'draft'` does not hide a word.** Verified: `GET /api/vocabulary` returns all
  142 rows including the 78 drafts. Coverage counts every row.
- **Don't invent a word to hit the number.** A wrong Jyutping tone teaches a
  mispronunciation. Four real, useful entries beat eight padded ones.
- **After editing:** `node tools/vocab-coverage-test.js` shows what is still empty.
- **When the 9 are filled:** `tools/vocab-coverage-test.js` is already wired into
  `tools/regression.js`, so it will start protecting the rule automatically.
